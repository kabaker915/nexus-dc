NEXUS DC - 3D/2D 机房构建与智能运维
================================================

一、一键启动
  1. 双击「启动.bat」。
  2. 窗口里出现启动地址后，浏览器会自动打开 http://127.0.0.1:5199/
  3. 使用期间不要关闭这个黑窗口；关闭即停止服务。
  4. 停止服务也可以双击「停止服务.bat」。

二、这个目录是什么
  index.html        页面入口
  src/              机房建模、2D 拓扑、运维仿真、NetDevOps 工具箱、真实接入代码
  vendor/three/     three.js r187（本地化，离线可用）
  docs/             截图与第三方许可说明
  server.mjs        本地静态服务 + 设备网关（127.0.0.1:5199）
  runtime/node.exe  便携版 Node.js 运行时（约 90MB，保证免安装可跑）
  启动.bat          一键启动
  停止服务.bat      结束占用 5199 端口的服务

三、模拟模式与真实模式（顶栏切换，快捷键 R）
  模拟模式（默认）
    使用内置遥测引擎：45 台模拟设备、端口流量、温度、告警、故障演练都可玩。
  真实模式
    1. 顶栏点「真实」，打开真实设备接入窗口。
    2. 网段已按本机网卡预填（如 192.168.1.0/24），点「扫描局域网」。
    3. 在发现的主机上点「接入」，程序会通过本机 SSH 识别厂商并采集状态。
    4. 可把真实设备「绑定」到机房模型设备：真实模式下它的 CPU/温度/端口数
       会覆盖仿真值，切回模拟模式立即恢复。
    5. 识别需要目标设备可达且已配置 SSH 公钥信任（免密登录）。

四、功能速查
  顶栏 3D / 2D        切换三维机房与二维平面/拓扑视图（快捷键 V）
  NetDevOps 按钮      多厂商 CLI 终端、配置生成/备份、批量巡检、诊断（快捷键 T）
  2D 拓扑图           「+ 外部设备」添加外接路由器/交换机/防火墙/云，拖拽定位，
                      点击节点配置管理地址与上联，可下发命令
  构建资源库          放机柜、上架设备、端口布线
  右侧面板            监控仪表盘、告警、事件、设备检查器

五、外接设备下发命令（可选）
  1. 2D -> 拓扑图 -> 点击一个外部设备节点。
  2. 填管理地址、端口、协议（SSH / HTTP），选择上联机房设备，保存。
  3. 点「下发命令」，勾选「真实下发」并二次确认后，由本机 server.mjs 网关
     通过 ssh 或 HTTP 真正连接设备执行；不勾选则只在本地生成模拟回显。

六、常见问题
  * 提示端口 5199 被占用：先运行「停止服务.bat」，或改 server.mjs 里的 PORT。
  * 双击后窗口闪退：右键「编辑」确认 runtime\node.exe 存在；也可安装 Node 18+。
  * 浏览器没有自动打开：手动访问 http://127.0.0.1:5199/
  * 页面空白：确认是通过 http 打开，不要直接双击 index.html。
  * 真实模式扫描不到设备：确认网段、SSH 端口开放、防火墙允许，以及页面是由
    本机 server.mjs 提供的（浏览器直接打开 HTML 无法调用网关接口）。
  * 真实设备"认证失败"：说明端口通但 SSH 免密未配置，需要把公钥放到设备上。
  * 布局会保存在浏览器 localStorage；清除浏览器数据会恢复示例机房。

【新增能力（P1/P2）】
· 工单：右侧「工单」页签；告警卡片点「工单」或设备「报修」即可建单，支持处理/完成/定位。
· 演练：监控面板「剧本演练」，内置市电中断、制冷失效、上联中断三套时间轴剧本，可中止。
· 容量/报告：仪表盘「24 小时趋势」「容量预测」；设置里「导出 PDF 报告」可打印或另存 PDF。
· 热力：按 H 或设置里勾选「机柜热力」；「顶部体积光」同样在设置里。
· SNMP / Redfish：NetDevOps → 真实模式 → 手动添加，协议选 SNMP v2c 或 Redfish（Redfish 默认 443/https）。
· 拓扑发现：真实模式「拓扑发现」会用 LLDP/CDP 邻居自动连上联。

【完整使用说明书】见仓库根目录 MANUAL.md（GitHub 直接渲染，含安装、每个按钮、真实设备接入、API、排障）。
【安全】/api/* 需要页面注入的 X-Nexus-Token，并校验 Host/Origin；Webhook 默认只允许 https 公网地址。
【性能】空闲渲染自动降到 12fps；设置里可切「流畅/均衡/画质」。
